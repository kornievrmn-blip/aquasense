# aquasense
AquaSense — це STEM-проєкт і десктопний застосунок у межах ЦСР ООН №6. Допомагає родинам формувати еко-звички, вести облік зекономленої води через зручний калькулятор, відстежувати прогрес за допомогою кільцевої діаграми та аналізувати тижневу статистику за допомогою вбудованого сховища.
