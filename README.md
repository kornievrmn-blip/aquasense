## 📌 Про проєкт
**AquaSense** — це десктопний застосунок, розроблений на **Python (Tkinter)**. Він допомагає усвідомлено споживати воду у побуті, рахувати скільки літрів ви зекономили завдяки корисним еко-звичкам (закритий кран під час чищення зубів, коротший душ тощо) та вести щоденну статистику.

### 🌟 Основні можливості:
- **Кільцева діаграма прогресу:** наочно показує, скільки води зекономлено сьогодні відносно денної мети (за замовчуванням — 50 л).
- **Інтерактивний калькулятор:** дозволяє швидко розрахувати економію води за хвилини виконання побутових завдань (можна використовувати кнопки або вводити свої значення).
- **Історія та статистика:** автоматично зберігає дані по днях у локальний файл (`water_data.json`), будує історію і дозволяє видаляти хибні записи чи скидати поточний день.
- **Зручне керування:** простий, сучасний та інтуїтивно зрозумілий інтерфейс.

## 🔗 STEM-складові проєкту[cite: 5]
- **S (Наука):** Вивчення проблеми дефіциту прісної води у світі та впливу побутового споживання на довкілля.
- **T (Технології):** Використання мови програмування Python, графічної бібліотеки Tkinter та формату JSON для обробки даних.
- **E (Інженерія):** Проєктування логіки взаємодії користувача з програмою (головний екран, калькулятор, історія, обробка помилок вводу).
- **M (Математика):** Формули розрахунку літрів за хвилинами, обчислення відсотків досягнення мети та побудова візуальних графіків.
